# VDR QA v0.13.0 — обычный make setup, без повышения прав

Эта версия заменяет обе сборки v0.12. Имена архивов новые, чтобы исключить путаницу.

## Существующий проект

Распакуйте fixes-overlay в корень проекта с заменой файлов.
Локальные .env, credentials, данные БД, результаты тестов и node_modules не включены
в обновление и не перезаписываются архивом. Собственные изменения исходников сохраните заранее.

Затем выполните единственную команду установки:

~~~bash
make setup
~~~

Не добавляйте sudo или переменные окружения. SKIP_BROWSER_OS_DEPS не требуется.
В начале будет напечатано:

~~~text
[bootstrap v0.13.0] User-mode setup; no automatic OS package installation.
~~~

## Полная установка

Распакуйте consolidated и выполните make setup из корня.
GNU Make, Bash, nvm, доступный пользователю Docker Engine/Compose и системные
библиотеки браузеров должны уже присутствовать на хосте.
Setup устанавливает пользовательские Node/npm/browser-зависимости и загружает образ k6.
Системные пакеты и права доступа ОС он не изменяет.
Если системной зависимости не хватает, соответствующий инструмент завершится ошибкой;
запроса повышения прав от наших установочных скриптов не будет.

После установки тесты запускаются прежними make-командами. Новому проекту по-прежнему
нужны make env-ui и данные тестового аккаунта перед make test-ui.

## Изменения и проверка

Сохранены все предыдущие исправления. Удалены автоматическая установка системных
пакетов и вызов playwright install-deps. Необязательный make browser-deps выполняет
только диагностику, не входит в setup и ничего не устанавливает.
Добавлен явный номер сборки в начало установки.

На Node 22.16.0: 70/70 unit/regression/guard tests (62 QA + 8 DB/performance).
Проверен план обычного make setup: нет sudo, apt-get, install-deps, --with-deps
или вызова скрипта системных зависимостей. Проверены архивы и Bash syntax.

Ранее в этой же сессии прошли npm ci API/web/QA, TypeScript QA и frontend build.
Полный браузерный E2E не подтверждён: загрузки Chromium/Cypress в среде проверки
возвращали повреждённые ZIP. Docker/PostgreSQL/k6 здесь не запускались.
