2. **P1 core UX:** multi-PDF drag/drop, mixed successes, per-file progress, offline/retry/partial failure, keyboard errors.
3. **P1 data:** byte-for-byte real Supabase PDF download, exactly 50 MiB vs +1, aborted upload retention, cleanup failures.
4. **P2 design and scale:** responsive mobile/tablet; semantics/labels/focus; large dataset pagination/cursors; bounded load with actual metrics.
